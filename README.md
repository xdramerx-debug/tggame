# Хроники Эха (Echo Chronicles)

Мобильная **idle RPG для Telegram Mini App** в духе Idle Heroes — с оригинальными механиками, названиями и балансом. Вертикальный экран, одна рука, сессии 3–7 минут.

## Ключевые системы
- **Отряд 6 героев: 2 фронта + 4 тыла.** Обычные атаки идут по позициям слева направо (фронт 1 → фронт 2 → тыл) — состав и расстановка решают исход боя.
- **6 фракций** (Тень, Бездна, Лес, Крепость, Свет, Тьма) и **ауры**: моно-фракция (+20% HP и профильный бонус), «Разрушение» (2+2+2: +13% ATK, +11% HP), «Искупление», «Радуга» (6 разных фракций), ролевые синергии (2 танка / 2 лекаря).
- **Чистая боевая симуляция** (`src/game/battle.ts`) без UI-зависимостей: навыки с шансом срабатывания, криты, вампиризм, щиты, баффы/дебаффы, реиграбельный лог событий. Визуализация: рывки, вспышки, всплывающие цифры урона, screen shake на критах, «сейчас будет каст»-маркеры, скорость x1/x2/x4, скип за рекламу (награда не больше ручного просмотра).
- **Idle-ядро**: авто-бой, оффлайн-доход с капом 12 часов (разбивка золото/опыт/шарды, кнопка «Забрать», x2 за rewarded-рекламу), автосохранение после каждого действия, версионирование сейва с миграцией.
- **Прогрессия**: уровни (золото + опыт), звёзды 5★→10★, тиры E1–E5 (нужна «еда»), T1–T5 (Transcendence), экипировка 4 слотов, призыв с публичными шансами и pity-счётчиком «до гарантированного 5★: N».
- **Режимы**: кампания на 100 этапов (босс каждые 10, главы), бесконечная Башня Эха, ежедневные/еженедельные задания, Вознесение (престиж), доска лидеров.

## Кривая сложности кампании (зафиксирована тестами `tests/unit/balance.test.ts`)
- Бюджет врагов на этапе N: уровень `1 + 0.7·N` (кап 100), ранг — ступень каждые 12 этапов (5★→6★→7★…), множитель статов `1 + 0.02·N` (линейный, чтобы мета-инвестиции — ауры/кузница/звёзды, суммарно ~×1.3–2.0 — успевали за кривой).
- Число врагов растёт вместе с отрядом игрока: 1 на этапах 1–2, +1 каждые 3 этапа, кап 6; боссы — элитная четвёрка (босс: +2 уровня, ×2 HP, ×1.2 ATK).
- Этапы 1–2 дополнительно смягчены (×0.8): у игрока один стартовый герой. Первый бой FTUE выигрывается гарантированно (force-win, dev-команды имеют приоритет).
- Контрольные точки winrate (100 сидов, без экипировки): этап 1 соло-старт ≥ 80%; этап 10 (первый босс) — стена, ломается +2 уровнями (≥70% на L8); этап 12+ проверяет ранги; этап 30 непроходим «голыми» уровнями даже с перекачкой — нужен ранг 8 (осколки/кузница).
- Темп боя (×1): round 520 мс, cast 1000 мс, attack 400 мс, damage 350 мс, death 520 мс; обычный бой ~10–15 с, первый бой FTUE с паузой и панелями — ~30–60 с (§13).

## Оригинальные механики (раздел 14 ТЗ — реализованы все пять)
1. **👻 Эхо павших** — поражение даёт 1–3 осколка душ (кап 20). Баффы за осколки: +10% ATK на 3 боя, +15% HP на 1 бой, воскрешение с 30% HP. Баффы заменяют, а не складывают друг друга.
2. **⚒️ Кузница душ** — рискованный крафт экипировки (8 осколков) с видимыми шансами 50/30/15/5; легендарные предметы дают уникальные боевые эффекты («первый удар — всегда крит» и др.); разбор предмета возвращает 2–3 осколка.
3. **🪞 Лабиринт отражений** — 5 этажей против копий собственного отряда с модификаторами, видимыми до боя; открывается после 10-го этапа кампании, сброс раз в неделю; полный проход — редкий герой + кристаллы.
4. **🌒 Пакт с тенью** — +30% урона герою на один бой ценой дебаффа после (-20% HP на 3 боя или молчание на 2 боя); дебафф виден на карточке; снятие за премиум-валюту.
5. **📖 Дневник странника** — 24 лор-записи, открываются за прогресс; каждая даёт пассивный бонус, полная коллекция — +10% ко всем статам и титул «Странник Эха».

## Монетизация и админ-инструменты
- **Telegram Stars**: разовые пакеты кристаллов ($0.99–$4.99), стартовый набор — один раз; награда выдаётся после серверной валидации (в прототипе — mock). Rewarded-реклама: +50 💎, x2 оффлайн, скип боя; не более 5 просмотров в день; interstitial нет.
- **Админ/промо-коды (раздел 15 ТЗ)**: скрытое поле (долгий тап 3 сек по версии в настройках), видимое поле промокода, валидация «на сервере» (`src/game/codes.ts`): белый список аккаунтов, срок действия, лимиты использований, rate-limit 5 попыток/мин с блокировкой на 10 минут, логирование, двойное подтверждение `admin_reset_save` (30 секунд). Dev-команды (`dev_fps`, `dev_hitboxes`, `dev_fast_forward 3600`, `dev_clear_cache`) работают только вне Telegram / при `?dev=1`.

## FTUE, удержание, аналитика
- Загрузочный экран с этапами («Пробуждение героев…»), FTUE из 4 шагов с паузой на первом ударе, ежедневный календарь на 7 дней, контекстные подсказки-плашки, «следующая цель» на главном экране, экран разбора поражения вместо Game Over.
- Звук: WebAudio-синтез BGM (хаб/бой) и SFX без ассетов; инициализация строго после первого тапа; mute сохраняется; пауза при сворачивании WebView.
- Аналитика: воронка open → boot → first_battle → first_upgrade → first_summon → first_stage_clear, длительность сессии, точка выхода; журнал виден в dev-панели и через `admin_log`.

## Готовность по чек-листу §13
| Пункт | Статус |
|---|---|
| Загрузка < 5 с | ✅ 112.5 kB gzip (бюджет 420), инлайн-сплэш в index.html до загрузки JS |
| Первый бой 30–60 с | ✅ ~10–15 с проигрывания + заставка ⚔️ + FTUE-пауза с подсказкой + панели наград |
| Первый бой выигрывается | ✅ этап 1: 97% соло-старт, FTUE-бои — гарантированный force-win |
| Оффлайн-кап ≤ 12 ч | ✅ `OFFLINE_CAP_H = 12`, разбивка золото/опыт/шарды, x2 за рекламу |
| Позиции имеют значение | ✅ фронт 0–1 принимает удары первыми, таргетинг слева направо (тесты) |
| Ауры видны | ✅ экраны «Отряд»/«Герои»: активные ауры с иконками и описанием |
| Звук только после тапа | ✅ `initAudio()` на первом pointerdown/keydown, BGM hub/battle, suspend при сворачивании |
| Платежи валидируются | ✅ концепт `validatePurchaseServerSide` (чек Telegram Stars → сервер), rewarded ≤ 5/день |
| Переживает убийство WebView | ✅ автосохранение после каждого действия + pagehide/visibilitychange + ErrorBoundary |
| Кнопки ≥ 44×44, safe-area | ✅ `.btn` min 44px, `env(safe-area-inset-*)`, viewport-fit=cover |
| Скип не платит больше просмотра | ✅ скип = те же награды, что и ручное проигрывание (тесты) |
| prefers-reduced-motion | ✅ анимации отключаются медиа-запросом |
| Админ-коды изолированы | ✅ в прод-режиме `allowAdminCodes=false` + whitelist по Telegram ID, rate-limit 5/мин |

## Архитектура
```
src/game/       чистая игровая логика (без React): battle, stats, auras, gacha,
                stages, forge, codes, diary, quests, offline, monetization, rng
src/state/      zustand-стор, сейв + миграции, начальное состояние
src/platform/   Telegram SDK, WebAudio, аналитика
src/screens/    экраны (home/battle/heroes/squad/summon/tower/labyrinth/forge/
                echo/diary/quests/leaderboard/shop/settings/more)
src/components/ навигация, модалки, тосты, UI-примитивы
```
Боевая логика полностью отделена от UI-состояния: `simulateBattle()` возвращает детерминированный лог событий, который `BattleScreen` проигрывает с выбранной скоростью.
