# 🧟 МЁРТВАЯ ЗОНА — мобильный 3D-шутер от третьего лица

Волновой survival-шутер на Three.js: заброшенный комплекс, волны зомби, процедурные
анимации и управление одним касанием. Без единого внешнего ассета — текстуры, модели,
звук и анимации генерируются кодом.

**Живая версия:** https://xdramerx-debug.github.io/tggame/

## Геймплей

- **Жанр:** TPS (вид от третьего лица), wave-survival.
- **Арена:** внутренний двор заброшенного комплекса ~54×54 м: бетонные стены с
  красной маркировкой, ящики, токсичные бочки, битые колонны, четыре дворовых
  лампы (одна мигающая, «разбитая»), холодный «лунный» свет и экспоненциальный туман.
- **Волны:** ходячие (hp 60, 2.2 м/с), бегуны (hp 40, 4.4 м/с, с волны 2),
  громилы (hp 260, 2.5× урон, с волны 3). Каждая волна добавляет ~9% HP и темп
  спавна; одновременно на арене не больше 13 зомби. Между волнами — 4.5 с передышки
  и бонус 250×номер волны.
- **Оружие:** винтовка — 26 урона (×2 в голову), магазин 30, авто-перезарядка,
  aim-assist по конусу 0.22 рад, трассеры, вспышка дула с динамическим светом.
- **Игрок:** 100 HP, рывок (0.22 с неуязвимой скорости, кд 2.6 с), комбо-множитель
  до ×3 за серию убийств (окно 4 с).
- **Дропы:** аптечка (+35 HP), патроны (полный магазин), «Шквальный огонь»
  (10 с: темп ×1.8, урон +15%). Шансы: 12% / 10% / 6% за убийство.
- **Рекорд** сохраняется в localStorage (`deadzone-best`).

## Управление (только тач)

| Жест | Действие |
|---|---|
| Драг левой половиной экрана | Динамический виртуальный джойстик (движение) |
| Драг правой половиной | Камера (yaw/pitch) |
| 🔥 (удерживать) | Автоматический огонь |
| » | Рывок |
| ⟳ | Перезарядка |
| ⏸ | Пауза |

На десктопе (для превью) работают WASD/стрелки, Space — рывок, R — перезарядка, мышь.

## Анимации — всё процедурное

Персонажи собраны из боксов с суставными pivots (плечи/локти/бедра/колени/голова):

- **Игрок:** idle-дыхание, цикл бега с наклоном, поза прицеливания с винтовкой,
  отдача оружия, анимация перезарядки (наклон винтовки), красная вспышка урона,
  падение при смерти.
- **Зомби:** восстание из земли при спавне, «зомби-походка» (вытянутые руки,
  покачивание, разболтанная голова), выпад-атака с замахом, стаггер при попадании,
  смерть с падением, оседанием и растворением + кровавые частицы.
- **Эффекты:** пул 700 аддитивных частиц (кровь, искры, пыль, гильзы спавна),
  трассеры, вспышка дула + PointLight, screen shake, FOV-кик рывка, мигающие лампы.

## Архитектура

```
src/
  game/     чистая логика без Three.js (rng, types, waves, scoring, powerups)
  engine/   движок: game.ts (оркестратор), world, player, zombie, weapons,
            particles, rig (процедурные модели/анимации), input, audio, haptics
  state/    store.ts — zustand-мост: снапшоты HUD ~10 Гц + события
  ui/       Hud.tsx, Menus.tsx, TouchControls.tsx — React-оверлеи
```

Правило: движок не знает про React, UI не знает про математику боя — только
снапшоты и события. Баланс живёт целиком в `src/game/types.ts` и `waves.ts`:
правка одного числа, а не костылей в коде.

## Разработка

```bash
npm install
npm run dev        # http://localhost:5173
npm run typecheck  # tsc --noEmit (strict, noUncheckedIndexedAccess)
npm run lint       # eslint strictTypeChecked
npm test           # vitest: waves/scoring/powerups/rng + coverage ≥70%
npm run build && npm run size && npm run check:dist
npm run test:e2e   # Playwright (chromium + SwiftShader)
```

Бюджет бандла: ≤420 kB gzip суммарно, ≤220 kB на чанк (three — крупнейший).

## CI/CD

- `.github/workflows/ci.yml` — typecheck, lint, unit, build, бюджет, dist-смоук +
  e2e на android-chrome-mobile (headless WebGL через SwiftShader). Провал e2e
  публикуется комментарием в PR.
- `.github/workflows/deploy.yml` — сборка и деплой на GitHub Pages при пуше в
  `main` и `arena/**`.
