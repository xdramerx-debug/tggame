# Астральный Легион (Astral Legion)

Мобильная Web Idle RPG в духе *Idle Heroes*, разработанная для мобильных браузеров и Telegram Mini Apps.

## Основные возможности
- **Авто-сражения 5 на 5 в реальном времени** — двухрядное построение (Авангард и Арьергард), накопление энергии, ультимативные способности с кинематографическими заставками и холстом частиц 60 FPS (`BattleVfxCanvas`), интерактивный активный навык **«Звёздный Гнев»**, ускорение боя `x1 / x2 / x3`.
- **12 уникальных героев и 4 стихии** — *Пламя*, *Природа*, *Лёд* и *Астрал* с системой уязвимостей и командных аур синергии.
- **Прокачка, Звёзды и Ковка снаряжения** — повышение уровня (`+1` / `+5`), пробуждение звёзд за осколки душ и улучшение 4 слотов экипировки.
- **Портал Созвездий (Гача)** — призывы `x1` и `x10` с гарантом редких/легендарных героев и автоматическим переводом дубликатов в осколки возвышения.
- **AFK Сундук, Быстрый Набег +2ч, Древние Реликвии и Башня Вечности** — накопление наград даже офлайн с сохранением прогресса в `localStorage`.

## Команды разработки
```bash
npm run dev        # Локальный сервер разработки
npm run typecheck  # Проверка типов TypeScript
npm run lint       # Проверка ESLint
npm test           # Юнит-тесты боевого движка, героев и призыва
npm run build      # Продакшн-сборка в dist/
npm run test:e2e   # Мобильные E2E тесты Playwright
```
