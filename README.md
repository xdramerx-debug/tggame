# 🏜️ ХАМСИН — мобильный FPS-выживание в песках

Оригинальный FPS в духе пыльной пустыни: оборона рубежа, вылазки за лутом, прокачка и закупка оружия. Без внешних ассетов — текстуры, модели, звук и анимации генерируются кодом.

**Живая версия:** https://xdramerx-debug.github.io/tggame/

## Геймплей

- **Вид:** от первого лица (как в CS2), соло, только тач.
- **Карта «Рубеж-9»:** ~80×80 м, саманные стены с кирпичной кладкой, арки, ящики, длинные прострелы, платформа в центре, две базы и смотровая вышка. Золотой песок с рябью ветра, пылевая дымка, HDR-небо и солнце-спрайт, мачта с мигалкой.
- **Цикл:** оборона от волн ↔ вылазка. Между волнами 40 с (первая — 20 с) — собирай ящики по карте, закупайся по радио. Ранний вызов волны даёт бонус +6₽ за оставшуюся секунду.
- **Враги:** солдаты 4 классов (пехотинец, автоматчик очередями, штурмовик-дробовик, марксман с лазером-телеграфом) + элита каждую 5-ю волну: **Титан** (таран, стан) и **Плевун** (кислота по дуге). До 10 врагов одновременно, HP/dmg/точность растут с волной.
- **Оружие:** Гадюка (пистолет, ∞ боезапас), Скорпион (СМГ), Шторм-АР, Обрез (8 дробин), Мираж-СВД. Тюнинг до T3 за деньги и детали: +8% урона, −12% разброс, +12% магазин за тир.
- **RPG:** уровни (120·lv^1.45 XP), 12 перков в 3 ветках — Выживание (HP/реген/броня), Огневая мощь (урон/перезарядка/крит), Мобильность (скорость/присед/рывок/гранаты). Мета-прогресс в `khamsin-meta-v1`.
- **Экономика:** деньги за фраги, бонусы волн, лут-ящики (деньги, детали, патроны, броня, гранаты, аптечки, XP).
- **Детали:** вьюмодель с отдачей/покачиванием/перезарядкой, трассеры, гильзы, искры, дым, кислотные брызги, следы от пуль, выживание: прыжок, присед, спринт, рывок (перк), гранаты, аптечки.

## Управление (только тач, десктоп — WASD+мышь)

| Жест | Действие |
|---|---|
| Левая половина — тяни | движение (край = бег) |
| Правая половина — свайп | прицел |
| 🔥 удерживай | огонь (все стволы — hold) |
| ⟳ | перезарядка |
| ⤒ | прыжок · step-up до 1.3 м |
| 🦆 | присед |
| » | рывок (открывается перком, кд 5 с) |
| 💣 / ❤️ | граната / аптечка |
| 📻 | радио — магазин |
| ⏸ | пауза |

Кнопки ≥44 px, safe-area, портрет/ландшафт.

## Техника

- **Движок:** Three.js 0.186 (дерево-шейк ~130 кБ gzip), React HUD overlay, Zustand-мост, Vite.
- **Сцена:** FogExp2, directional sun + hemi, программные текстуры (песок, саман, дерево, металл, мешки, камень, небо), blob-тени, без shadow maps на мобилках — быстро.
- **Анимации:** все процедурные (ходьба, отдача, перезарядка, падение, спавн из песка, пыль).
- **Звук:** WebAudio — выстрелы по стволам, шаги, взрывы, рёв титана, шипение плевуна, ветер; `setMuted` + `unlockAudio`.
- **Чистая логика:** `src/game/*` без Three.js — 71 unit-тест, покрытие 70%+.

## Деплой

`main` и `arena/**` → GitHub Pages (concurrency `pages`). CI: `quality` (lint/typecheck/unit/build/size) → `e2e` (android-chrome-mobile) → deploy.

## Баланс

Тюнинг оружия — единственный регулятор урона/разброса; волны — единственная шкала сложности; перки — мета, не ломают забег. Все числа в `src/game/*` — меняй одно, не хакай.

## Лицензия

Оригинальная карта и ассеты — авторские, не копия de_dust2 / CS2.
