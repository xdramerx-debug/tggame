# FREAKPIT

**Подпольный турнир уродов.** 3D-файтинг в духе классических аркадных драк, но со
своими бойцами, собранными из примитивов прямо в браузере. Мобильный Telegram
Mini App: горизонтальный экран, два больших пальца, best-of-3.

> Проект переписан с нуля. Предыдущая игра (TENEBRIS) удалена полностью —
> история коммитов осталась, код нет.

## Что это

Затопленный карьер, ржавый забор, три лампы и четыре урода, которые выясняют,
кто выйдет отсюда на своих ногах. Раунд — 60 секунд, до двух побед, суперы,
чип-урон, комбо через отмену попавшего удара и wake-up с неуязвимостью.

| Боец | Роль | Силуэт |
| --- | --- | --- |
| **ГРЫЗЛО** | тяжёлый, 1120 HP, кислота | гора сала с клыками |
| **ШВЕЯ** | баланс, длинные руки, рывок | башня из четырёх рук и швов |
| **ОКО** | зонинг, телепорт, взгляд | парящий глаз на стебле |
| **ПЕЧЬ** | агрессия, броня, огонь | печка на ногах с трубой |

## Управление

| Элемент | Действие |
| --- | --- |
| Стик (слева) | ходьба, вверх — прыжок, вниз — присед |
| **БЛОК** | удерживать — блок (отдельная кнопка, не «назад») |
| **УДАР** | быстрый панч, в воздухе — прыжковый удар |
| **ПИНОК** | тяжёлый удар / в приседе — подсечка (лоу, сбивает) |
| **СПЕШЛ** | 1 полоса метра, у каждого своя механика (броня, телепорт, снаряд) |
| **СУПЕР** | 3 полосы, длинная анимация, большой урон |

Комбо: попавший удар можно отменить в спешл или супер — это единственный способ
собрать серию. Блок режет урон до чипа, но лоу нельзя блокировать стоя, а хай
(прыжковый удар) — сидя. После нокдауна 34 тика подъёма и 8 тиков неуязвимости:
«мити» на подъёме не работает.

## Технологии

- **React 18 + Vite 8 + TypeScript strict** (`noUncheckedIndexedAccess`, без `any`).
- **Three.js** — сцена, процедурные модели, искры, тряска камеры.
- **Симпуляция отдельно от рендера**: чистый TypeScript, фиксированные 60 Гц,
  без DOM и Three.js, поэтому полностью покрыта юнит-тестами.
- **Zustand** — экраны и настройки; **framer-motion** — только баннеры и переходы ≤ 300 мс.
- **WebAudio-синтез** — все звуки генерируются кодом, ни одного аудиофайла.
- **Telegram Mini Apps SDK** — тема, fullscreen, HapticFeedback (никакого `navigator.vibrate`).

## Ассеты

Внешних ассетов нет вообще: модели, портреты, иконки, звуки и фон генерируются
кодом. Поэтому «пересобрать всё с нуля» — это ровно:

```bash
npm ci
npm run build
```

Никаких отдельных шагов генерации, никаких бинарников в репозитории, никаких
лицензий на чужие модели.

## Команды

```bash
npm run dev          # http://0.0.0.0:5173, работает и в браузере телефона
npm run typecheck    # tsc --noEmit, strict
npm run lint         # eslint, strictTypeChecked + react-hooks
npm test             # vitest: frame data, блоки, комбо, KO, таймер, AI
npm run build        # tsc + vite build
npm run size         # бюджет бандла в gzip
npm run check:dist   # проверка собранного dist перед деплоем
npm run test:e2e     # Playwright, Pixel 7 landscape + iPhone 13 landscape
```

## Структура

```
src/
  fight/         симуляция: типы, Fighter, Battle, AI (без DOM)
  characters/    ростер: 4 бойца и их frame data
  render/        Three.js: сцена ямы, процедурные модели, искры
  game/          фиксированный цикл матча (MatchEngine) и React-хук
  input/         тач-ввод без React-состояний
  audio/         WebAudio-синтез sfx и эмбиента
  platform/      Telegram SDK, Wake Lock
  state/         zustand-стор экранов и настроек
  ui/            меню, выбор бойца, HUD, тач-контролы, результат
tests/
  unit/          vitest
  e2e/           Playwright (только мобильные ландшафтные профили)
```

Подробности правил и frame data — в [docs/DESIGN.md](docs/DESIGN.md).

## Деплой

GitHub Pages, источник — **GitHub Actions** (Settings → Pages → Build and
deployment → Source: GitHub Actions). Workflow `Deploy FREAKPIT` собирает `dist`
и публикует артефакт на каждый push в `main` или `arena/**`. Pages отдаёт именно
сборку, а не корень репозитория — иначе открывался бы `index.html` с `/src/main.tsx`
и приложение висело бы на пустом экране.

## Мобильные требования, которые соблюдены

- 100dvh, `env(safe-area-inset-*)`, `touch-action: none`, блок контекстного меню,
  double-tap zoom, pull-to-refresh, выделения текста.
- Тач-таргеты ≥ 48×48 px (основные кнопки 56–66 px), зазор ≥ 12 px.
- Screen Wake Lock, пауза и глушение звука на `visibilitychange`/`blur`.
- Авто-деградация графики при FPS < 45 (тени и частицы отключаются на лету).
- Переходы экранов 200 мс, баннеры 180 мс — UI не блокируется.
