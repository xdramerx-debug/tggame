# TENEBRIS

**Мобильный 3D roguelite survival RPG для Telegram Mini Apps.** Только телефон, только landscape, только касания.

> Статус: **этап 12 из 13 — интеграция с Telegram**. Третий этаж заканчивается ареной Смотрителя глубин: 340 HP, две фазы ярости (×1.15 и ×1.35 к урону, быстрее кулдаун) и полоса здоровья сверху. Победа над ним завершает забег как победа, смерть — как конец забега. Каждый забег приносит **угли** (база + убийства + этажи + сундуки), которые тратятся в **алтаре** на постоянные улучшения: HP, урон, стамина, броня, крит и стартовые пайки. Итоги забега пишутся в Dexie (`stats`), покупки — в `meta`. **Звук (этап 10)** целиком синтезируется кодом: 19 WAV-дорожек 22.05 kHz mono (508 kB) собираются `npm run assets` вместе с моделями, Howler играет их через WebAudio с групп-миксами, троттлингом повторов и паузой вместе с игрой. **Полировка (этап 11)** добавляет то, что отличает «работает» от «приятно»: уровни внутри забега с кривой опыта и бонусами к статам, хит-стоп на попадании и крите, бюджет частиц по пресету, пауза с продолжением вместо выброса в меню и честный тост при авто-деградации качества. **Telegram (этап 12)**: прогресс дублируется в CloudStorage, меню здоровается по имени из launch-параметров, есть приглашение друга ссылкой `startapp`, а нативная кнопка «назад» привязана ко всем оверлеям. Дальше — оптимизация и релиз (см. дорожную карту).

## Что уже работает

- **Единый WebGL-контекст** на всю сессию: `WebGLRenderer` c `powerPreference: 'high-performance'`, ACES tone mapping, `PCFSoftShadowMap`.
- **Orbit-камера** третьего лица: pitch −15°…+45°, зум 2.5–8 м, smooth follow 0.1 с, collision-aware (мгновенно поджимается у стены, плавно возвращается).
- **Пост-обработка**: UnrealBloom (0.4 / порог 0.85) + Vignette + FilmGrain (0.02) + FXAA; SSAO только на high.
- **Адаптивное качество**: пресеты high / medium / low, авто-понижение при FPS < 45, защита от осцилляции (8 с между переключениями), ручной выбор в настройках.
- **Мобильный слой**: принудительный landscape (Telegram + Screen Orientation API + CSS-оверлей «Поверните телефон»), safe-area через `env()` и Telegram insets, Screen Wake Lock, пауза по `visibilitychange`/`blur`/`pagehide`, запрет контекстного меню, double-tap zoom, pinch-zoom страницы и pull-to-refresh.
- **Процедурное подземелье (этап 4)**: BSP на 56×56 тайлов, 7 комнат, коридоры 2 м по MST с петлями, типы комнат из `src/data/rooms.json` (боевая, сокровищница, привал, алтарь + вход/выход), потолки 3–5 м, двери с открыванием по приближению, мебель и колонны instanced, свет по бюджету тарифа, `FogExp2 0.04`, спуск на следующий этаж через руну выхода. Детерминированность по сиду (`?seed=1234`).
- **PBR-материалы** с процедурными (Canvas2D) albedo/normal/roughness и UV в мировых координатах (0.5 UV/м) — текстура не «сетит» на стыках тайлов.
- **Telegram**: авто-тема (`themeParams`), haptic-обёртка (только `HapticFeedback`, без `navigator.vibrate`), MainButton/BackButton, fullscreen, `disableVerticalSwipes`, подтверждение закрытия.
- **Настройки** (чувствительность камеры, размер кнопок, левша/правша, авто-атака, прозрачность HUD, вибро, качество, инверсия Y) с сохранением в IndexedDB (Dexie, схема из ТЗ).
- **Splash по стадиям** (движок → текстуры → модели → звук) с реальным прогрессом загрузки.
- **Физика (этап 3)**: Rapier3D WASM в отдельном чанке, фиксированный шаг 60 Гц с аккумулятором и ограничением 4 подшага, капсульный character controller (slide, autostep 0.35 м, snap-to-ground, уклон до 50°), гравитация, raycast камеры по физическим коллайдерам с исключением капсулы игрока, dev-визуализация коллайдеров (`?physics=1`).
- **Dev-оверлей производительности**: FPS, frame time, worst frame, draw calls, tris, активный пресет (`?perf=0` чтобы скрыть).

- **Telegram (этап 12)**: CloudStorage как зеркало записи (Dexie читается всегда, облако поднимает прогресс только если локально пусто), приветствие по имени из launch-параметров без сохранения личности, инвайт `t.me/<bot>?startapp=ref_<id>` с санитайзом payload, привязка нативной кнопки «назад» к паузе, настройкам, титрам и алтарю, честный статус «где живёт прогресс» в настройках. Все вызовы SDK обёрнуты: в браузере и на старом клиенте поведение деградирует тихо, без падения.
- **Полировка (этап 11)**: опыт за убийства идёт в **уровни забега** (`src/data/levels.json`: кривая 40 × 1.38, потолок 12, +6 HP/+2 урона/+4 стамины за уровень), бонусы уровня складываются с мета и снаряжением в одной точке, а новый максимум HP приходит заполненным. POP: удар/крит/полученный урон замораживают симуляцию на 40–100 мс (`fx/HitStop`, часы принадлежат движку, камера и FPS-монитор идут по реальному времени), частицы подчиняются `particleRatio` пресета, ☰ открывает **паузу** вместо мгновенного выхода в меню, а авто-деградация качества сообщает о себе тостом. HUD показывает уровень и полосу опыта.
- **Аудио (этап 10)**: `scripts/audio/` — `wav.ts` (PCM 16 бит, 44-байтный заголовок), `synth.ts` (детюн-осцилляторы со sweep, one-pole шум, ADSR, comb-reverb, нормализация и fade краёв) и `sfx.ts` (19 звуков: удар, крит, промах, шаги, дверь, сундук, костёр, паёк, голод, спуск, рёв и фазы босса, победа, смерть, амбиент-луп). `npm run assets` рендерит их, валидирует формат/пик и пишет `manifest.json` v2. В рантайме `src/game/audio/` разделяет политику и плумбинг: `AudioManager` (группы `sfx`/`ui`/`ambience`, `retriggerMs`-троттлинг, jitter тона шагов, mute на паузе и на `visibilitychange`) и лениво подгружаемый `HowlBackend`. Сцена звук не воспроизводит — она отдаёт `onSound(id)`, движок решает, что и как громко. Громкости эффектов и атмосферы — в настройках (`settings.v1`).
- **Пайплайн ассетов (этап 5)**: `npm run assets` собирает из THREE-геометрии героя (1.3k tris, 19 костей, 7 клипов), костяного стража (5 клипов) и мебель (сундук, алтарь, жаровня, факел, колонна) и экспортирует в GLB через `GLTFExporter` — без Blender и без единого бинарника в git. GLB валидируется (магия/скин/клипы) и заново загружается в тестах тем же `GLTFLoader`, что и в игре.
- **Скелетная анимация**: `CharacterModel` — конечный автомат (локомоция по скорости, одноразовые attack/dodge/hit, терминальная death), клипы атаки и рывка масштабируются под геймплейные окна, `hit` не сбивает замах.
- **Выживание (этап 8)**: `src/data/survival.json` хранит весь баланс — скорость голода, пороги сытости, множители регенерации и урона, силу пайка, параметры костра. Сытость убывает 0.34/с (плюс 0.16/с на бегу), ниже 40 — «голоден» (регенерация ×0.6, урон ×0.88), ниже 12 — «истощение» (регенерация ×0.3, урон ×0.7 и 0.9 HP/с). Пайки падают с монстров и всегда лежат в сундуках, едятся кнопкой 🍖. Костёр лечит 35 % HP, кормит и возвращает стамину, но только один раз и только если рядом нет врагов. Смерть замораживает забег и открывает экран итогов.
- **Босс и мета-прогрессия (этап 9)**: на третьем этаже самый дальний зал типизируется как `boss` (вес 0 в раздаче комнат — арена ставится явно) и получает Смотрителя глубин — 340 HP, 14 брони, 17 урона, две фазы ярости из `monsters.json` (`at 0.66` → ×1.2 скорость / ×1.15 урон, `at 0.33` → ×1.45 / ×1.35). Фазы считает чистая `ai/BossPhase.phaseMultipliers`, босса нельзя стаггерить чип-уроном и нельзя выгрузить по дистанции. Полоса здоровья появляется в радиусе 20 м, фазы отмечены точками. Смерть босса = победа: экран итогов с кнопками «Новый забег / Алтарь / В меню». Награда — угли по данным `src/data/progression.json` (база 4 + 1 за убийство + 6 за этаж + 1 за сундук + 40 за победу), 6 апгрейдов с растущей ценой; бонусы складываются со снаряжением и применяются существующим `PlayerStats.applyBonuses`, поэтому купленное чувствуется с первого удара следующего забега.
- **Лут и снаряжение (этап 7)**: таблица предметов в `src/data/items.json` (12 баз в трёх слотах, редкости common/rare/epic с множителем силы), взвешенный ролл редкости, дроп с монстров (золото всегда, предмет в 22 % случаев) и из сундуков (золото + 1–2 предмета). Сумка на 12 слотов, три слота снаряжения, панель инвентаря с золотом, бонусами и цветом редкости; надевание мгновенно пересчитывает `PlayerStats` (урон, броня, HP, стамина, крит). Переполнение сумки не теряется молча — тост сообщает, сколько предметов не влезло. Сундук — настоящая сущность с GLB-моделью, открывается через кнопку взаимодействия и только один раз.
- **Боёвка (этап 6)**: таблица монстров в `src/data/monsters.json` (костяной страж с 1 этажа, ревенант со 2-го), ИИ `EnemyBrain` — idle → chase → windup → strike → recover со стаггером, линией видимости и leash; урон с бронёй по кривой `armor/(armor+50)` и минимумом 20 %, криты ×1.8 и разброс ±10 %, i-frames после попадания и абсолютные i-frames рывка. Игрок рубит конусом (`targetsInArc`, 2.6 м, 100°), стамина гейтит удар и рывок. Спавн — `EnemyDirector`: план на этаж детерминирован сидом, тела создаются при подходе к комнате (≤6 одновременно), убитая комната остаётся пустой. Обратная связь: всплывающие цифры урона, искры/моты на `InstancedMesh`, тряска камеры, haptic. Смерть — респавн у входа с полным восстановлением до системы мета-прогрессии.

## Управление (этап 2)

| Жест | Действие |
| --- | --- |
| Левый нижний угол (для правши) | Виртуальный стик: база 80 px, кнопка 36 px, мёртвая зона 15 %, база «прилипает» к пальцу в радиусе 120 px, возврат пружиной 150 мс |
| Свайп по противоположной половине | Вращение камеры, 0.25°/px (настраивается 0.1–0.5), инерция 100 мс |
| Пинч там же | Зум 2.5–8 м |
| Тап по зоне камеры | Быстрый удар (отключается в настройках) |
| ⚔️ | Атака конусом 100° / 2.6 м, таргет 76 px, кулдаун 0.45 с, 10 стамины |
| 🔥 / ❄️ | Скиллы, 60 px (заглушки до этапа 6) |
| 🛡️ | Уворот с i-frames, 60 px, кулдаун 1.2 с, 20 стамины |
| ⚡ | Взаимодействие, 56 px: сундук рядом или руна выхода |
| 🎒 | Инвентарь: 3 слота снаряжения, сумка на 12 предметов, золото (ставит игру на паузу) |
| 🍖 | Съесть паёк: +34 сытости и немного HP, счётчик на кнопке |
| ⚡ | У костра — отдых (лечит и кормит), если рядом нет врагов |

Раскладка зеркалируется настройкой «Левша», размер кнопок масштабируется S/M/L, HUD — прозрачностью. Все таргеты ≥48 px, зазор 12 px, отклик на `pointerdown` (≤50 мс), haptic на нажатие.

## Стек

TypeScript (strict, без `any`) · Vite · React 18 · Zustand · TailwindCSS · Framer Motion · Three.js r186 · Rapier3D 0.21 (WASM) · Dexie · @telegram-apps/sdk v3. Howler — звук.

Целевые браузеры: iOS 15+ (WebKit в Telegram), Chrome Android 100+. Десктопной версии нет и не будет.

## Команды

```bash
npm ci            # установка зависимостей
npm run dev       # dev-сервер на 0.0.0.0:5173 (preview в браузере)
npm run build     # strict typecheck + production build
npm run preview   # предпросмотр собранной версии
npm run typecheck # только tsc --noEmit
npm run lint      # ESLint (type-aware)
npm run test      # Vitest: камера, качество, процедурные текстуры, safe-area
npm run test:e2e  # Playwright: Pixel 7 + iPhone 13 (landscape)
npm run size      # проверка бюджета бандла (< 3 MB gzip)
```

Первый запуск E2E требует браузеров: `npx playwright install --with-deps chromium webkit`.

## Структура

```
src/
├── scripts/models/  генераторы героя/монстра/пропсов, риг, скиннинг, GLB-экспорт
├── game/
│   ├── core/        Engine, Renderer, Loop, CameraRig, Quality, PerfMonitor
│   ├── physics/     PhysicsWorld (Rapier), CharacterBody, FixedStep, капсулы
│   ├── visual/      PostFX, PhysicsDebug, DamageNumbers, HitEffects, текстуры и карты нормалей
│   ├── assets/      AssetLoader (GLB + кэш + SkeletonUtils-клоны), манифест моделей
│   ├── entities/    PlayerController, CharacterModel, HeroView, Enemy, Chest, placeholder
│   ├── combat/      Health (броня + i-frames), damage (криты/разброс), meleeArc, monsterTable
│   ├── ai/          EnemyBrain — конечный автомат монстра
│   ├── player/      PlayerStats — HP, стамина, профиль атаки, бонусы снаряжения
│   ├── loot/        itemTable, Inventory, LootTable, RunState (золото/XP/сумка)
│   ├── survival/    Survival — голод, пороги, множители, пайки
│   ├── scenes/      DungeonScene (этап 4), TestScene (эталон этапа 3)
│   ├── world/       bsp, DungeonGenerator, DungeonMesh, Door, Props, RoomLights, EnemyDirector
│   └── GameHost.ts  синглтон canvas + engine
├── input/           VirtualJoystick, CameraSwipe, CooldownTracker, InputLayer, TouchButton
├── mobile/          orientation, safeArea, wakeLock, fullscreen, gestures, lifecycle
├── telegram/        init, theme, haptic, buttons, viewport
├── ui/              Splash, MainMenu, GameScreen, Settings, Credits, Orientation, PerfOverlay
├── store/           Zustand: game + settings (persist в Dexie)
├── db/              Dexie v1 (saves, meta, stats, settings) + export/import
└── types/           engine, scene
```

Ассеты генерируются скриптами: модели — `scripts/models/` + `scripts/build-assets.ts` (этап 5), текстуры — процедурные в рантайме, аудио — `scripts/audio/` (WAV PCM, Howler). `npm run assets` пересобирает всё с нуля; `.glb` и `manifest.json` не коммитятся.

## Производительность

| Метрика | Бюджет | Сейчас (этап 1) |
| --- | --- | --- |
| Bundle gzip | < 3 MB | **~2.0 MB** (Rapier WASM 1.67 MB в отдельном ленивом чанке, приложение ~104 kB) |
| Draw calls | < 100 | ~28 на этаж (3 merged + ~10 instanced + двери + 4 меша героя) |
| Ассеты моделей | ≤ 1 MB | **343 kB** GLB (герой 123, монстр 133, мебель 87) |
| Лут | 0 сетевых запросов | таблица `items.json` в бандле, роллы на `Math.random`, 12 инстансов max |
| Выживание | 1 тик на фиксированный шаг | чистые числа в `Survival`, HUD читает снапшот 10 Гц |
| Босс | 1 тело на арену | один `Enemy` с фазами из данных, полоса здоровья опрашивается 8 Гц |
| Аудио | ≤ 600 kB | **508 kB** (19 дорожек 22.05 kHz mono), буферы грузятся в фоне на этапе `audio` прогресса |
| Мета | 0 кадров | `MetaState` — чистые числа; запись в Dexie сразу на покупку (один тап = один `put`), экран алтаря статичен |
| Ощущения | 0 лишних кадров | хит-стоп масштабирует `dt` (40–100 мс), а не останавливает цикл; частицы — 2 instanced-меша по бюджету пресета |
| Боёвка | ≤ 6 активных монстров | 6 капсул + 6 скиннинг-моделей; тела создаются по близости |
| Эффекты удара | 0 аллокаций в бою | 2 `InstancedMesh` (по 40 частиц) + пул из 12 спрайтов урона |
| Physics | фикс. 60 Гц | 60 Гц, ≤4 подшага/кадр, ~50–80 статических коллайдеров этажа |
| Point lights | ≤ 4 (high/medium), ≤ 2 (low) | ровно по бюджету: факел + ближайшие комнаты + руна выхода |
| Input UI per frame | без React-рендеров | rAF пишет transform/CSS-переменные |
| Tris на сцене | < 120k | ~10–20k на этаж |
| Первый экран | < 2.5 с | splash скрывается сразу после boot движка |
| Пресеты | high/medium/low | авто-переключение по FPS |
