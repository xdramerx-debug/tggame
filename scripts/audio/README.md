# Аудио

Этап 5 аудио не добавляет. На этапе 10 звук будет сгенерирован кодом: WAV PCM
22.05 kHz mono (удар, шаги, открытие двери, окружение) с опциональным OGG, если
в окружении есть энкодер. Источник — `scripts/audio/*.ts`, запуск через
`npm run assets`.

Требования: только собственные или CC0 сэмплы, каждая сторонняя запись — строка в
`CREDITS.md`. Сгенерированные `.wav` не коммитятся (см. `.gitignore`).
