# Blender-скрипты (необязательный путь)

Основной пайплайн моделей живёт в `scripts/models/` и **не требует Blender**:
персонажи и мебель собираются из THREE-геометрии, скиннингуются вручную и
экспортируются в GLB через `GLTFExporter` (`scripts/models/glb.ts`).
Запуск: `npm run assets` (см. корневой README).

Этот каталог — место для скриптов `bpy`, когда понадобится скульпт/ручное
моделирование (этапы 9–13: босс, уникальные пропсы). Требования к ним:

1. Результат — те же имена файлов, что в `src/game/assets/manifest.ts`
   (`models/hero.glb`, `models/monster-skeleton.glb`, …).
2. Тот же контракт рига: имена костей без точек (`upperArm_L`, `thigh_R`, …),
   rest-позиция с идентичными вращениями, лицо в −Z, ступни на y = 0.
3. Те же имена клипов: `idle, walk, run, attack, dodge, hit, death`.
4. Скрипт обязан быть детерминированным и вызываться из `npm run assets`.

Пока ни один `.blend`/`.py` здесь не нужен: всё, что есть в игре, генерируется
кодом и проверяется тестами `tests/unit/assetPipeline.test.ts`.
