# Текстуры

Текстуры в игре процедурные: `src/game/visual/textures/` (альбедо, карты нормалей,
шероховатость) считаются на Canvas2D в рантайме и не требуют файлов.

Этот каталог — для офлайн-пайплайна этапов 9–13: запекание тех же процедурных
текстур в KTX2/Basis (нужны `basisu`/`toktx`, которых нет в CI-образе) и
preview-рендеры карт. Скрипты обязаны использовать те же генераторы
(`createStoneTextures`, `createCrystalTexture`) и те же сиды, иначе вид в игре и
в запечённом ассете разойдётся.

Правило пайплайна: сгенерированные файлы не коммитятся (см. `.gitignore`), в
репозитории живут только скрипты и параметры.
